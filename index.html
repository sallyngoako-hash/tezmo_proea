How this works
  1. Needs an approved email (the access request goes to the owner). No PC, no extra software.
  2. Your login and trading password go once to mtapi.io (https://mt5.mtapi.io) to open a session. The password is never saved in this browser, only the session token.
  3. Demo or Real is taken from the server name: names containing Demo or Trial count as demo, everything else is treated as real and asks for an extra confirmation.
  4. Server lists may be incomplete: pick Other server to type yours exactly as in your broker email.
